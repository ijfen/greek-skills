# Greek Skills

An interactive knowledge graph of Ancient Greek skills: eleven strands (A–K), each node a testable skill, each edge a prerequisite.

Open `index.html` in a browser. Click a skill to mark it mastered; select one to trace its prerequisites upward and what it unlocks downward. Progress is saved in the browser, and "Copy progress link" carries it to another device.

Draft 2, October 2026. The graph data lives in the `DATA` object inside `index.html`.
